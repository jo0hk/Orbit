# 미션 대사 세트 (2학기 4주차)

> 작성: AI/PM · 2026-09-21 (원본 대조 후 개정)
> 원본: `docs/reference/mission-list-1st-semester.md` · 판정 조건: `docs/mission-spec.md`
> 코드 정의: `ai/app/missions.py` (이 문서는 코드에서 생성됨. 수정은 코드에서)

## 작성 규칙

1. **공백 포함 45자 이내.** 1학기 압축 규칙을 따릅니다.
2. 무전 프로토콜 — `치직-` 으로 시작, `대장님` 호칭, `오버` / `라저` / `교신 종료` 로 종료.
3. 상황마다 **변형 2종**. 같은 문장이 반복되면 몰입이 깨집니다.
4. `led` / `vibe` / `oled_expression` 은 1주차 확정 enum만 씁니다.
5. **재시도 대사에 압박을 넣지 않습니다.** 미션 미달은 실패가 아니라 유예입니다.

> ⚠️ 원본 AI 피드백은 60~80자로 길고 따뜻한 톤입니다("와아, 눈이 부셔요!"). 45자 규칙 때문에 압축하면서 어조가 건조해졌습니다. 어느 쪽을 택할지는 `docs/mission-spec.md` 7절 참조.

# 1단계 — 시스템 점검

## M1. 아침 온기 나누기 `m_warm_touch`

- **성공 조건** 터치 신호가 3초 이상 연속 유지
- **원본 검증 방법** 터치 센서가 3초 이상 연속 신호 감지

**제안**
- A `치직- 대장님, 키링을 손바닥으로 3초간 감싸 쥐어 주십시오. 오버`  *(37자)*
- B `치직- 온기 수신 대기 중. 3초간 감싸 쥐어 주십시오, 대장님. 오버`  *(39자)*

**성공**
- A `치직- 대장님의 온기 수신 완료. 회로가 예열됐습니다. 라저`  *(33자)*
- B `치직- 온기 확인! 오늘 하루도 무사히 착륙해 봐요, 대장님. 라저`  *(37자)*

**재시도**
- A `치직- 온기 신호가 끊겼습니다. 조금 더 오래 쥐어 주십시오. 오버`  *(37자)*
- B `치직- 수신 미완. 천천히 다시 시도하셔도 됩니다. 교신 종료`  *(34자)*

> 원본 1단계 첫 미션. 연속 유지 판정이라 3회 카운트보다 오탐이 적음
> HW 확인: 손에 쥔 상태의 정전용량 변화가 3초간 안정적으로 잡히는지

## M2. 엔진 시동 인사 `m_engine_start`

- **성공 조건** 짧고 강한 충격 2회 (간격 300~1500ms)
- **원본 검증 방법** 가속도 센서가 짧고 강한 충격 2회 감지

**제안**
- A `치직- 대장님, 제 머리를 두 번 톡톡 두드려 깨워 주십시오. 오버`  *(37자)*
- B `치직- 엔진 시동 대기 중. 두 번 두드려 주십시오, 대장님. 오버`  *(37자)*

**성공**
- A `치직- 대장님 응답 확인! 엔진 가동 준비 완료됐습니다. 오버`  *(34자)*
- B `치직- 시동 성공! 오늘의 미션을 하달해 주시겠습니까. 라저`  *(33자)*

**재시도**
- A `치직- 충격 감지 실패. 조금 더 또렷하게 두드려 주십시오. 오버`  *(36자)*
- B `치직- 신호가 약합니다. 한 번 더 부탁드립니다, 대장님. 오버`  *(35자)*

> 원본은 '두드려 깨우기'. 흔들기(궤도 회전 테스트)와 달리 충격 패턴이라 걷기와 구분이 쉬움
> HW 실측 필요: 충격 임계값과 2회 간격 범위

# 2단계 — 감각의 깨움

## M3. 태양광 패널 전면 개방 `m_solar_panel`

- **성공 조건** 제안 시점 50 lux 이하 → 10분 내 200 lux 이상이 연속 30초 유지
- **원본 검증 방법** 조도 센서가 낮은 수치에서 급격히 상승하여 일정 시간 유지

**제안**
- A `치직- 기지 광량 부족. 커튼을 열어 패널을 개방해 주십시오. 오버`  *(37자)*
- B `치직- 태양 에너지 수신 대기 중. 창을 열어 주십시오, 대장님. 오버`  *(39자)*

**성공**
- A `치직- 태양 에너지 쏟아집니다! 기지 밝기 최적화 완료. 라저`  *(34자)*
- B `치직- 광량 급상승! 기분이 한결 환해지네요, 대장님. 라저`  *(33자)*

**재시도**
- A `치직- 아직 어둡습니다. 준비되시면 다시 시도해 주십시오. 오버`  *(35자)*
- B `치직- 광량 변화 미미. 천천히 하셔도 됩니다. 교신 종료`  *(32자)*

> 원본의 '일정 시간 유지'를 30초로 구체화. 손전등이 스치는 것을 오판하지 않기 위함
> 커튼을 연 것과 전등을 켠 것은 센서로 구분 불가. 원본 1단계 '태양광 패널 점검'(전등)과 사실상 같은 판정

# 3단계 — 행성 표면 탐사

## M4. 베이스캠프 반경 확보 `m_basecamp_100m`  ⏸️ *비활성*

- **성공 조건** 집 출발 후 누적 이동 거리 100m 이상
- **원본 검증 방법** 핸드폰 GPS 기반 이동 거리 측정 (실시간 지도 트래킹)

**제안**
- A `치직- 베이스캠프 반경 100m 확보 임무를 제안합니다. 오버`  *(34자)*
- B `치직- 기지 밖 100m 지점까지 정찰을 권장합니다, 대장님. 오버`  *(37자)*

**성공**
- A `치직- 베이스캠프 주변 안전 확인 완료. 대기 질 양호합니다. 라저`  *(37자)*
- B `치직- 정찰 완수! 조금 더 깊이 탐사해 볼까요, 대장님. 라저`  *(35자)*

**재시도**
- A `치직- 정찰 중단 확인. 언제든 재개 가능합니다. 교신 종료`  *(33자)*
- B `치직- 여기까지도 훌륭합니다. 기록 보관하겠습니다. 교신 종료`  *(34자)*

> 원본 거리는 100m. 300m는 근거 없는 상향이었음
> 앱 확인 필요: 샘플 간 5m 미만 무시(드리프트), 10km/h 초과 구간 제외(차량)
> 100m는 GPS 오차(±10m)와 가까우므로 드리프트 필터가 특히 중요

# 4단계 — 현지인과 교신

## M5. 첫 번째 외교적 수사 `m_first_greeting`  ⏸️ *비활성*

- **성공 조건** 앱에서 사용자가 완료 보고
- **원본 검증 방법** 마이크 센서 및 STT로 인사말 키워드 추출

**제안**
- A `치직- 현지인에게 인사 교신을 시도해 보시겠습니까, 대장님. 오버`  *(36자)*
- B `치직- 외교 임무 제안. 점원에게 인사 한마디 어떠십니까. 오버`  *(35자)*

**성공**
- A `치직- 현지인과 첫 교신 성공! 목소리 주파수 당당했습니다. 라저`  *(36자)*
- B `치직- 외교적 첫걸음 확인! 대장님, 아주 훌륭했습니다. 라저`  *(34자)*

**재시도**
- A `치직- 다음 기회에 시도해도 좋습니다. 서두르지 마십시오. 교신 종료`  *(38자)*
- B `치직- 접수. 준비되셨을 때 다시 보고해 주십시오. 교신 종료`  *(34자)*

> ⚠️ 원본 검증 방법(상시 마이크 + STT)은 채택하지 않음. 타인과의 대화를 상시 청취해야 하므로 본인과 상대방 모두의 개인정보 문제가 발생함
> 자가 보고로 대체. 4단계 서사를 유지하면서 프라이버시 문제를 피하는 유일한 방법

## 미션 거부 시

사용자가 거부 의사를 밝히면 **미션 대사가 아니라 예외 대화 1번**을 씁니다.
→ `ai/prompts/exceptions.md` 1. 탐사 거부

거부 후에는 대체 미션을 제안하고, **재차 권유하지 않습니다.** 쿨다운 3시간 후 재제안 가능합니다.

| 거부한 미션 | 대체 제안 |
| --- | --- |
| 태양광 패널 전면 개방 | 아침 온기 나누기 |
| 베이스캠프 반경 확보 | 태양광 패널 전면 개방 |
| 첫 번째 외교적 수사 | 태양광 패널 전면 개방 |

## 미션 완료 알림이 대화에 끼어들 때

미션 성공 이벤트는 사용자가 다른 이야기를 하는 도중에도 들어옵니다.

- 사용자 발화에 **먼저 응답**하고, 미션 축하를 **같은 응답 뒤에 한 문장으로** 붙입니다
- 45자를 넘기면 미션 축하를 **다음 턴으로 미룹니다**
- 축하를 이유로 사용자 질문을 무시하지 않습니다

> 6주차 검증 항목입니다. 5주차 프롬프트 템플릿에 반영하세요.
