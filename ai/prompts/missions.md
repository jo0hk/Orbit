# 미션 대사 세트 (10-01 교체)

> 작성: AI/PM · 2026-10-01
> 미션 구조: 2026-09-17 회의 확정안 (단계당 1개, AI 서버 판정) · 판정 조건: `docs/stage-mission-judgement.md`
> 코드 정의: `ai/app/missions.py` (이 문서는 코드의 대사를 옮긴 것. 수정은 코드에서 하고 이 문서를 맞춥니다)
> 반응 문형: `docs/mission-context-injection.md` 4절

> **10-01 교체.** 4주차의 센서 미션 5개(터치·가속도·조도·GPS·자가 보고) 대사를 09-17 회의에서 확정한 미션 4종으로 바꿨습니다. 이전 판정 조건은 `docs/mission-spec.md`에 기록으로 남아 있습니다.

## 작성 규칙

1. **공백 포함 45자 이내.** 1학기 압축 규칙을 따릅니다.
2. 무전 프로토콜 — `치직-` 으로 시작, `대장님` 호칭, `오버` / `라저` / `교신 종료` 로 종료.
3. 상황마다 **변형 2종**. 같은 문장이 반복되면 몰입이 깨집니다.
4. **`실패`라는 단어를 쓰지 않습니다.** 조건 미달은 "아직"이며 같은 날 다시 할 수 있습니다.
5. **재시도 대사에 압박을 넣지 않습니다.** 금지어: 빨리, 꼭, 반드시, 다시 해야, 왜.
6. 이 대사는 LLM에 참고 대사로 주입됩니다(복사 금지, 변주). 그대로 재생하는 고정 대사가 아닙니다.

# 1단계 — 시스템 점검

## 앱 대화창에 오늘 기분 단어로 입력하기 `EMOTION_TEXT`

- **입력 경로** TEXT · **판정** RULE
- **성공 조건** 기분 표현이 1개 이상. 어떤 기분이든 성공

**제안**
- A `치직- 대장님, 오늘 기분을 한 단어로 송신해 주십시오. 오버`  *(34자)*
- B `치직- 시스템 점검 시간입니다. 지금 기분이 어떠십니까. 오버`  *(34자)*

**성공**
- A `치직- 본부에 긴급 타전! 대장님 첫 상태 보고 수신 완료. 라저`  *(36자)*
- B `치직- 기분 신호 수신! 교신 감도가 200% 올라갔습니다. 라저`  *(36자)*

**재시도**
- A `치직- 신호가 짧습니다. 지금 기분을 한 단어로 보내 주십시오. 오버`  *(38자)*
- B `치직- 기분 신호가 약합니다. 편하실 때 다시 송신 바랍니다. 오버`  *(37자)*

> 감정 내용으로 성패를 가르지 않음. '우울해'도 성공
> '귀찮아' 단독은 거부가 아니라 기분으로 처리
> 회의 표의 판정 주체는 '백엔드(AI 보조)'였으나 앱 텍스트가 AI 서버를 거치므로 AI 서버가 판정

# 2단계 — 감각의 깨움

## 창밖 날씨를 보고 오빗에게 음성으로 보고하기 `WEATHER_VOICE`

- **입력 경로** VOICE · **판정** RULE
- **성공 조건** 날씨 표현 + 날씨 API 범주와 일치 또는 인접

**제안**
- A `치직- 대장님, 창밖 날씨를 관측해 음성으로 보고 바랍니다. 오버`  *(36자)*
- B `치직- 외부 행성 주파수 수신 시간. 오늘 하늘은 어떻습니까. 오버`  *(37자)*

**성공**
- A `치직- 은하 전역에 관측 보고 전파! 맑은 하늘 확인, 대장님. 라저`  *(38자)*
- B `치직- 창밖 관측 확인! 대장님 덕에 기상 데이터 확보입니다. 라저`  *(37자)*

**재시도**
- A `치직- 기상 센서와 다릅니다. 창밖을 한 번 더 봐 주시겠습니까. 오버`  *(39자)*
- B `치직- 날씨 정보가 안 잡힙니다. 하늘이 어떤지 알려 주십시오. 오버`  *(38자)*

> 관찰을 API보다 우선. 인접 범주 허용, 정반대만 재시도
> 날씨 API 장애 시 날씨 표현만 있으면 성공
> STT 신뢰도 0.5 미만이면 판정하지 않고 예외 대화 5번(되묻기)

# 3단계 — 행성 표면 탐사

## 동네 랜드마크(건물, 조형물) 사진 찍기 `LANDMARK_PHOTO`  *(비활성 — 사진 업로드 경로 확정 후)*

- **입력 경로** PHOTO · **판정** VISION
- **성공 조건** 야외 사진, 피사체가 건물·조형물·간판, 신뢰도 0.6 이상

**제안**
- A `치직- 동네 랜드마크를 찾아 사진으로 전송 바랍니다. 오버`  *(32자)*
- B `치직- 행성 표면 탐사 임무. 건물이나 조형물을 찍어 주십시오. 오버`  *(38자)*

**성공**
- A `치직- 탐사 일지에 첫 지형 기록! 대장님 덕에 지도가 넓어집니다. 라저`  *(40자)*
- B `치직- 행성 표면 사진 수신! 본부가 들썩입니다, 대장님. 라저`  *(35자)*

**재시도**
- A `치직- 실내로 판독됩니다. 바깥 풍경을 찍어 주시겠습니까. 오버`  *(35자)*
- B `치직- 랜드마크가 흐립니다. 건물이나 조형물을 다시 담아 주십시오. 오버`  *(40자)*

> 카메라 촬영만 허용(갤러리 불가). 사진 원본은 판정 후 저장하지 않음
> 사람이 주 피사체면 사물을 찍도록 안내

# 4단계 — 현지인과 교신

## 대중교통 이용해 세 정거장 이상 이동하기 `TRANSIT`  *(비활성 — 사진 업로드 경로 확정 후)*

- **입력 경로** PHOTO · **판정** VISION
- **성공 조건** 승차·하차 인증 사진 + 시간차 5분 이상 + 두 촬영 지점 직선거리 1km 이상

**제안**
- A `치직- 현지 교통망 탐사 임무. 세 정거장 이동을 제안합니다. 오버`  *(37자)*
- B `치직- 대장님, 버스나 지하철로 세 정거장 정찰 어떠십니까. 오버`  *(36자)*

**성공**
- A `치직- 은하 교통망 접속 성공! 대장님, 사회 궤도 진입입니다. 라저`  *(38자)*
- B `치직- 세 정거장 정찰 완수! 본부에 역사적 기록으로 남깁니다. 라저`  *(38자)*

**재시도**
- A `치직- 이동 거리가 조금 짧습니다. 다음에 이어 가셔도 좋습니다. 오버`  *(39자)*
- B `치직- 인증 사진 판독이 어렵습니다. 원하시면 다시 찍어 주십시오. 오버`  *(40자)*

> 상시 마이크를 쓰지 않음. 승차(단말기·하차벨)와 하차(정류장·역명판)를 사물로 인증
> 좌표는 거리 계산에만 쓰고 저장하지 않음

## 미션 거부 시

사용자가 거부 의사를 밝히면 **미션 대사가 아니라 예외 대화 1번**을 씁니다. → `ai/prompts/exceptions.md` 1. 탐사 거부

- 결과 API를 호출하지 않습니다(보류). 미션은 `IN_PROGRESS` 로 남고 다음날 같은 단계 미션이 다시 배정됩니다.
- 단계당 미션이 1개라 대체 미션은 없습니다. 재차 권유하지 않습니다.
- 1단계에서 "귀찮아" 단독은 거부가 아니라 기분 표현입니다.
