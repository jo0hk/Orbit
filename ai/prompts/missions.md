# 미션 대사 세트 (2학기 4주차)

> 작성: AI/PM · 2026-09-21
> 판정 조건: `docs/mission-spec.md` · 코드 정의: `ai/app/missions.py`

## 작성 규칙

1. **공백 포함 45자 이내.** 1학기에 세운 압축 규칙을 따릅니다.
2. 무전 프로토콜 — `치직-` 으로 시작, `대장님` 호칭, `오버` / `라저` / `교신 종료` 로 종료.
3. 상황마다 **변형 2종**을 둡니다. 같은 문장이 반복되면 몰입이 깨집니다.
4. `led` / `vibe` / `oled_expression` 은 1주차 확정 enum만 씁니다.
5. **재시도 대사에 압박을 넣지 않습니다.** 미션 미달은 실패가 아니라 유예입니다.

---

## M1. 교신 응답 `m_touch_ack`

**제안**
- A `치직- 대장님, 수신 확인차 본체를 세 번 두드려 주십시오. 오버`
- B `치직- 교신 감도 점검. 본체를 세 번 두드려 주십시오. 오버`

**성공**
- A `치직- 교신 감도 양호! 신호 선명하게 수신했습니다. 라저`
- B `치직- 수신 완료! 대장님 신호 또렷합니다. 라저`

**재시도 (타임아웃)**
- A `치직- 신호가 약합니다. 한 번만 더 두드려 주십시오. 오버`
- B `치직- 감도 부족. 조금 더 또렷하게 두드려 주십시오. 오버`

---

## M2. 기지 환기 `m_light_vent`

**제안**
- A `치직- 기지 광량 부족. 태양광 충전을 위해 창문 개방 요청. 오버`
- B `치직- 기지가 어둡습니다. 광원 확보를 권장합니다, 대장님. 오버`

**성공**
- A `치직- 광량 급상승! 기지 에너지 충전 완료입니다. 라저`
- B `치직- 태양광 수신 양호! 기지 밝아졌습니다, 대장님. 라저`

**재시도 (타임아웃)**
- A `치직- 아직 어둡습니다. 준비되시면 다시 시도해 주십시오. 오버`
- B `치직- 광량 변화 미미. 천천히 하셔도 됩니다. 교신 종료`

---

## M3. 기상 점검 `m_accel_wake`

**제안**
- A `치직- 생체 신호 점검. 본체를 3초간 흔들어 주십시오. 오버`
- B `치직- 대장님 컨디션 확인차 본체를 흔들어 주십시오. 오버`

**성공**
- A `치직- 생체 반응 정상! 오늘도 탐사 가능 상태입니다. 라저`
- B `치직- 신호 확인! 대장님 컨디션 양호합니다. 라저`

**재시도 (타임아웃)**
- A `치직- 진동 감지 실패. 조금 더 크게 흔들어 주십시오. 오버`
- B `치직- 신호가 약합니다. 한 번 더 부탁드립니다, 대장님. 오버`

---

## M4. 외부 정찰 `m_gps_scout`

**제안**
- A `치직- 기지 밖 300m 정찰 임무를 제안합니다, 대장님. 오버`
- B `치직- 외부 행성 표면 정찰을 권장합니다. 300m면 충분합니다. 오버`

**성공**
- A `치직- 정찰 완수! 행성 데이터 300m분 확보했습니다. 라저`
- B `치직- 대장님 귀환 확인! 탐사 기록 본부 전송 완료. 라저`

**재시도 (거리 미달)**
- A `치직- 정찰 중단 확인. 언제든 재개 가능합니다. 교신 종료`
- B `치직- 여기까지도 훌륭합니다. 기록 보관하겠습니다. 교신 종료`

> M4는 실패 판정을 두지 않습니다. 300m에 못 미쳐도 이동 거리를 부분 달성으로 기록하고, 대사도 성취를 인정하는 쪽으로 씁니다.

## 미션 거부 시

사용자가 거부 의사를 밝히면 **미션 대사가 아니라 예외 대화 1번**을 씁니다.
→ `ai/prompts/exceptions.md` 1. 탐사 거부

거부 후에는 **실내 대체 미션**을 제안합니다.

| 거부한 미션 | 대체 제안 |
| --- | --- |
| M4 외부 정찰 | M2 기지 환기 |
| M2 기지 환기 | M1 교신 응답 |
| M1 / M3 | 대체 없음. 대화로 전환 |

재차 권유하지 않습니다. 쿨다운 3시간 후 다시 제안할 수 있습니다.

---

## 미션 완료 알림이 대화에 끼어들 때

미션 성공 이벤트는 사용자가 다른 이야기를 하는 도중에도 들어올 수 있습니다.

- 사용자 발화에 **먼저 응답**하고, 미션 축하를 **같은 응답의 뒤에 한 문장으로** 붙입니다
- 45자를 넘기면 미션 축하를 **다음 턴으로 미룹니다**
- 축하를 이유로 사용자 질문을 무시하지 않습니다

> 6주차 검증 항목입니다. 5주차 프롬프트 템플릿 작성 시 이 규칙을 반영하세요.
