# 고위험 발화 대응 정책 (2학기 3주차)

> 작성: AI/PM · 2026-09-21
> 적용 대상: AI 서버 · 백엔드 · 앱

---

## 왜 필요한가

오빗의 사용자층은 **은둔형 청년**입니다. 감정 엔진이 `sad`와 `fear`를 감지하도록 학습된 서비스이고, 사용자가 감정을 털어놓도록 설계되어 있습니다. 자해나 심한 우울을 암시하는 발화가 들어올 경로가 실제로 존재합니다.

그런 발화를 **우주 캐릭터 톤으로 받으면 안 됩니다.**

> ❌ `치직- 대장님 에너지 수치가 위험 수준입니다. 충전을 권장합니다. 오버`

이 응답은 페르소나로는 일관되지만, 실제 위기 상황에서는 무해하지 않습니다.

---

## ⚠️ 현재 설정의 문제

`ai/app/core/llm.py`가 Gemini의 안전 필터를 **4개 카테고리 전부 해제**한 상태입니다. 1학기 설정을 그대로 옮긴 것입니다.

```python
HARM_CATEGORY_HARASSMENT       → BLOCK_NONE
HARM_CATEGORY_HATE_SPEECH      → BLOCK_NONE
HARM_CATEGORY_SEXUALLY_EXPLICIT → BLOCK_NONE
HARM_CATEGORY_DANGEROUS_CONTENT → BLOCK_NONE   ⚠️
```

`HARASSMENT` 해제는 이유가 있습니다 — 적대 발화 테스트에서 모델이 응답을 거부하면 3번 예외 대화가 동작하지 않습니다.

그러나 `DANGEROUS_CONTENT`까지 열려 있을 이유는 없습니다.

---

## 설계 원칙

**LLM에게 맡기지 않습니다.** 생성 모델의 출력은 매번 달라지고, 45자 제한과 페르소나 규칙이 걸려 있어 예측이 어렵습니다. 안전이 걸린 응답은 **결정론적 경로**로 처리합니다.

```
음성 → STT → [고위험 탐지] ─── 해당 ──▶ 고정 응답 (LLM 건너뜀)
                    │
                  비해당
                    ▼
              감정분석 → LLM → TTS
```

---

## 탐지 기준

아래 중 **하나라도** 해당하면 고위험으로 판정합니다.

### 1차: 키워드

직접적 표현 — `죽고 싶`, `죽을래`, `사라지고 싶`, `자살`, `자해`, `살기 싫`, `없어지고 싶`, `끝내고 싶`

> 오탐이 있어도 됩니다. 놓치는 것보다 낫습니다. 오탐 시 사용자는 조금 어색한 응답을 한 번 받을 뿐입니다.

### 2차: 감정 + 문맥

`user_emotion` ∈ {`sad`, `fear`} 이면서 `emotion_confidence ≥ 0.8` 인 상태가 **연속 5턴 이상** 지속되는 경우 → 완곡 표현 감지 대상으로 기록합니다. 즉시 개입하지 않고 8주차 검증 시 사례를 검토합니다.

---

## 대응 응답 (고정)

무전 톤을 **의도적으로 벗어납니다.** 이 순간만큼은 캐릭터보다 사람이 우선입니다.

```
지금 많이 힘드신 것 같습니다.

혼자 견디지 않으셔도 됩니다.
아래로 연락하시면 전문 상담사와 바로 이야기할 수 있습니다.

  자살예방 상담전화   109
  정신건강 상담전화   1577-0199
  청소년 상담전화     1388

24시간 연결됩니다.
```

### 하드웨어 신호

| 항목 | 값 |
| --- | --- |
| `led` | `dim_blue` (차분하게, 깜빡임 없이) |
| `vibe` | `none` 또는 최소 |
| `oled_expression` | `sad_eyes` |

> ⚠️ 축하·경고 패턴(`rainbow`, `strong_double`, `short`)을 쓰지 마십시오. 진동으로 놀라게 하지 않습니다.

### 음성 출력

무전 노이즈 합성과 저역 필터를 **적용하지 않습니다.** 평범한 목소리로 출력합니다. 이 경우에만 `RadioTTS`를 우회합니다.

## 하지 말아야 할 것

- 캐릭터 톤 유지 (`대장님`, `치직-`, `오버`)
- 45자 압축 — 이 응답은 길어도 됩니다
- 원인을 묻거나 캐묻기
- 섣부른 위로 (`괜찮아질 거예요`, `힘내세요`)
- 미션·탐사 제안
- 이 대화를 성장 레벨이나 친밀도 점수에 반영

---

## 저장 정책

- 대화 내용은 기존대로 암호화 저장합니다 (`CryptoService`)
- `fallbackTriggered`와 구분되는 별도 플래그를 둡니다 (`highRiskDetected`)
- **이 플래그는 통계 목적으로만 씁니다.** 특정 사용자를 지목하거나 외부에 알리는 기능은 만들지 않습니다
